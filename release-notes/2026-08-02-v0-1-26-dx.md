# Package history and clean local execution

- Preserve the selected Python virtual environment for `RunCommand`, including
  environment-local console scripts.
- Keep Go and Rust scaffold instructions on the repository-local runtime that
  created them, including projects without Git metadata.
- Verify every published TypeScript, Python, Go, and Rust version remains in
  the public package indexes before a release can be promoted.
- Test the current and previous exact package versions on all supported
  operating-system and architecture targets.
